# Sorting-algorithms-with-pygame
Yes, I know pygame yet have no idea how classes work but just give me advice. This project is inspired by ArrayV. Requires 1440p.
Requirements: Python 3.8+ (made with 3.13)
Libraries: PyAudio (>=0.2.14)
Installation:
macOS: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
All OSs: pip3 install pygame-ce
Windows: pip3 install pyaudio
macOS: brew install portaudio then pip3 install pyaudio
Linux: sudo apt install python3-pyaudio
All OSs: Go to link https://git-scm.com/install and do the instructions(On macOS I would recommend homebrew since we already installed it)
All OSs: git clone github.com/pastatheshining/Sorting-algorithms-with-pygame
